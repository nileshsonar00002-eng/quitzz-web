# quitzZ - Gamified Quit Smoking App Landing Page

Official, high-converting landing page for **quitzZ** ("QUIT. BREATHE. FREE.").

## Features
- **Dark Mode Aesthetic**: Deep Obsidian (`#0A0A0A`), Charcoal cards (`#141414`), Neon Lime vitality green (`#84CC16`), and Gold/Amber rewards (`#F59E0B`).
- **Interactive ROI Engine**: Real-time savings and biological life calculations with range sliders, number inputs, preset chips, and compound growth projections.
- **60s Craving Breaker**: Interactive in-browser 4-4-4 box breathing guide to crush sudden cravings and earn Z-Coins.
- **Scientific Bio-Timeline**: Step-by-step biological recovery roadmap from 20 minutes to 1 year clean.
- **Google Play Focused**: Clean Play Store badges and direct mobile QR code download.
- **Custom Favicon & Official Branding**: Complete set of brand icons and multi-resolution favicons.

## Project Structure

## Running Locally
You can run a local server with Python:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
